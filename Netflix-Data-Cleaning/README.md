# Netflix Data Cleaning and Preparation

## Objective

The objective of this task is to clean and prepare the Netflix titles dataset using Python and Pandas.

## Tools Used

- Python
- Pandas
- Google Colab
- GitHub

## Data Cleaning Steps

1. Standardized column names.
2. Removed unnecessary spaces.
3. Checked and removed duplicate rows.
4. Standardized text values.
5. Handled missing values.
6. Converted `date_added` to datetime format.
7. Verified data types.
8. Saved the cleaned dataset.

## Files

- `netflix_titles.csv` - Original dataset
- `netflix_titles_cleaned.csv` - Cleaned dataset
- `netflix_data_cleaning.ipynb` - Cleaning code
- `requirements.txt` - Required Python package

## Conclusion

The Netflix dataset was cleaned and prepared for further analysis using Python and Pandas.
