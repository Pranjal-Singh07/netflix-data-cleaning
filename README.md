# Netflix Data Cleaning and Preparation

## Objective

The objective of this task is to clean and prepare the Netflix titles dataset using Python and Pandas.

## Tools Used

- Python
- Pandas
- Google Colab
- GitHub

## Dataset

The Netflix dataset contains information about movies and TV shows, including title, director, cast, country, release year, rating, duration, and description.

## Data Cleaning Steps

- Standardized column names.
- Removed unnecessary leading and trailing spaces.
- Checked and removed duplicate records.
- Standardized text values for consistency.
- Handled appropriate missing values.
- Converted `date_added` to datetime format.
- Verified the data types of the columns.
- Saved the cleaned dataset as a separate CSV file.

## Short Summary of Changes

The Netflix dataset was cleaned using Python and Pandas. Duplicate records were checked and removed, unnecessary spaces were cleaned, and text values were standardized for consistency. Appropriate missing values were handled using `Unknown`, and the `date_added` column was converted to datetime format. The data types were also verified, and the cleaned dataset was saved as a separate CSV file.

## Conclusion

The dataset was successfully cleaned and prepared for further analysis using Python and Pandas.
